## About

Argues that traditional loss-prevention tools (HAZOP, fault trees, bow ties, PRA) rest on incomplete assumptions about accident causes in modern computer-intensive, tightly coupled systems. Treats safety as a **control** problem rather than a component-failure problem; applies STAMP/STPA/CAST to process-industry cases (Texas City, Shell Moerdijk, etc.). Complements the structured reference extraction of *Engineering a Safer World* already in this library.
